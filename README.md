# An-lisis_ventas_rentabilidad
Proyecto basado en análisis previo en SQL, donde se generaron tablas para calcular unidades vendidas, utilidad, ingresos, margen y métricas por producto, cliente y fecha. Estos datos alimentan un dashboard interactivo en Power BI que analiza ventas, rentabilidad, ticket promedio y compara productos más vendidos y más rentables.
